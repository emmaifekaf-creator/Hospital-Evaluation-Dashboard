# Hospital-Evaluation-Dashboard --City General Hospital


**Author.** Okafor Emmanuel

**Date.** 2025-11-23



##Project Background

City Hospital is experiencing severe operational crises:ER overcrowding,poor patient management, bed and ward allocation,staff burnout, financial losses, medication store mismanagenent
high lab retest rate. This project analyzes available hospital data and produces an interactive Excel dashboard with
actionable recommendation



##Project Objective

- Identify root causes of operational crises
- Analyze patient demography, admission history,staff workload,medication stock,lab efficiency,and financial data
- Build an interactive Excel dashboard to inform board-level decisions
- Recommend action plans to stabilize hospital operations



  ## Datasets

**City Hospital Dataset.xlsx**--patient_id,age,gender,Visit_date,admission_type


## Dashboard Features

- Key KPIs: total patients, total duration(days),totalndoctors,admission year, tatal weeks

- Visuals: age group distribution, medication chart,billing chart
- Interactivity: filters/slicers for Age group, date range, staff workload



  ## Key Findings
  
-Majority of patients arev within the age range of 23--83 years
-Uneven distribution of staff workload
-Inventory mismatch: critical drugs short while others near expiry
- Obesity and hypertension are usually inconcluvive



  ## Recommendations

  1. Allocate beds and wards based on age-group trends
  2. Balance staff workload using workload analytics
  3. Implement automated stock monitoring for medication
  4. Use more advanced lab test equipment and tighten QC process
  5. Monitor KPIs and run a montyly operaion review with stakeholders
  6. Include visit time for patients in the records
